## 6. スマホ画面の実際の不具合修正（最終検証）

- モバイルの成績比較テーブル（最小横幅725px）を囲む `.scroll` が `overflow:visible` だったため、390px画面でページ全体のスクロール幅が751pxまで拡大していた。
- 固定下部メニューまで幅751pxになり、スクロール位置によって中央競馬の結果ボタンがタップできなくなっていた。
- `index.html` のモバイル用 `.scroll` を `overflow-x:auto; overflow-y:hidden; max-width:100%; -webkit-overflow-scrolling:touch` に修正。幅広の比較表だけを横スクロール可能に変更。
- `tests/mobile-ui-smoke.cjs` に、`documentElement.scrollWidth <= clientWidth + 2` と下部ナビゲーションのヒット判定を追加。
- GitHub Actions のスマホ操作テスト成功: https://github.com/sora4270-ux/keiba-lab/actions/runs/45031536866
- 総合監査成功: https://github.com/sora4270-ux/keiba-lab/actions/runs/45031536842
