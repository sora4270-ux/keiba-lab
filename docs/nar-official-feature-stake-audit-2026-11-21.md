# NAR公式特徴量・券種別資金配分の監査（2026-11-21）

## 官方項目の所在と時点管理

NAR 2026年5月版の公式CSV資料:
https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf

* racelist.csv 「馬場」(26列目): 過去レースの馬場状態。月次CSV上の存在と**T-15観測済み**は別問題。
* horselist.csv 「負担重量」(17列目): 当該出馬表の数値。帯広は「積載重量」として別扱い。
* racelist.csv 「コーナー通過順1..8」(60列目以降): 結果に関連した通過情報。**同一レースの脚質特徴量として投入禁止**。過去日のレースだけを用いた脚質推定は別途設計する。
* payout.csv: 公式払戻金。取消・返還・同着を別途照合しないときは除外する。

解析: python scripts/audit_nar_feature_availability.py --month 2026-11
公式ZIPを提供してオフライン検証する場合: --zip /path/to/monthly_race.zip

**主な制限:** 月次データの馬場は「発走15分前に取得可能だった」の証拠にならない。発走15分前に当日ZIPを時刻付きで保存しない限り、ライブ予想への導入を認めない。公式に「脚質」列はなく過去通過順からの推定に留まる。公表データの利用条件を守り、公式サイトへの過剰アクセスを避ける。

## 固定予算・同一レース比較

python scripts/backtest_nar_stake_allocation.py --month 2026-11

5,000円/対象レースの**仮想予算**を全方式で固定。事前保存されている順位・三連複候補・三連単候補を使い、対象レースを統一し、分配単位100円を適用。プランは balanced / no_trifecta / wide_focus / trio_focus / trifecta_focus。ワイド候補は事前保存済み上位5頭の組み合わせ。各券種の予算で全候補を買えなければ保存順の先頭候補を選択。全点BOXを必ず買う仕様ではなく、資金配分の診断専用。

適格性: T-15の時刻整合、確定結果3頭（同着除外）、相異なる買い目、記録済み全対象券種の払戻とワイド上位3組を要求。戻り額0は公式確認済みの着外に限る設計。ただし履歴内の公式由来の払戻**主張を外部から再認証していない**ため、この計算は独立監査済みROIではない。実投票・実収支でもない。

同じレースごとに配分方式を比較する。日付70/30に分けて後半を別掲するが、方式のチューニングや機械的採用は行わない。月次/長期・平地/ばんえいを区別。高回収率でも過去データへの適合を排除できない。

テスト: GitHub Actionsの NAR comprehensive test and stake audit は全Python単体テスト・全Nodeテスト・自己診断・仮想資金配分を実行。公式ZIPの現物取得はベストエフォートで、失敗時も「取得証明なし」と出す。解析レポートはAction artifactに30日間保存。

**変更方針:** 公開予想、買い目、既存の履歴、実際の投票、マネーの移動、モデル係数には一切変更を加えない。
