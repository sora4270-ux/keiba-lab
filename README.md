# KEIBA LAB v3.7 — 回収率の自動計算（2026-11-02）

- **計算式**：参考回収率（%）= 仮想払戻金合計 ÷ 仮想購入金額合計 × 100。各買い目を100円ずつ購入したと仮定し、実際の購入・損益とは区別します。

- **確定前、未入力・未取得の払戻は未集計**。単純な3着判定で対応しない同着・返還・取消などのケースは計算対象外です。実際の投票履歴や金銭管理を記録する機能ではありません。

- 同着、払戻返還、除外など特殊な結果は単純な3着照合・参考収支の対象外です。主催者発表を確認してください。地方競馬公式の仕様は[データダウンロード説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)を参照。
- バックアップ形式は従来の keiba-lab-ledger-v3 に互換です。古い記録に払戻がなければ未登録として表示します。

# KEIBA LAB v3.4 — 地方競馬の自動予想・三連複と三連単の買い目・的中率

## 三連複の買い目表示（v3.4）
- 自動予想の各レースカードに「三連複の買い目」を常時表示します。3頭の順序は問いません。予想時点の全着順組の合計確率を集計し、**異なる組合せ上位最大8点**を保存します。各レースに三連複本線1点（上位3頭）も残します。
- v3.3以前に予想が保存されたレースについては、**保存済みの三連単候補12点から順不同の組合せに変換**して表示します。この変換は過去の確定結果を使用せず、後出し予想になりません。過去予想の三連複候補点数は8点より少ない場合があります。
- 三連複候補の的中率は複数点のうち1点でも一致したレースの割合です。本線1点の的中率と混同しないでください。券種・点数によって的中率は大きく変わります。
- 「レース予想」タブの手動予想でも、現在選択した三連単候補を順不同に変換した三連複買い目を表示します。手動の履歴集計の三連複は従来通り本線1点です。
- v3.6から確定払戻と参考収支の表示に対応しました。投票購入は行いません。100円／点の金額は仮想計算で、収益性や利益の保証ではありません。

## 今回追加した自動モード
- 対象は地方競馬（NAR）の当日開催レース。**JRA中央競馬は対象外**。
- GitHub Actionsの `.github/workflows/nar-auto.yml` が JST 9:00〜22:55を目安に5分ごとに公式CSVの配布ZIPを取得します。GitHubの遅延・制限で予定通り動かない可能性があります。
- `scripts/update_nar.py` は発走10分以上前、かつ結果が未公表のレースのみ予想し、予想日時、三連単12点と三連複の最大8点を記録。結果公開後は別処理で1〜3着を照合します。予想は後から上書きされません。
- 自動予想と的中率は `data/auto/nar_predictions.json` に保存され、トップページに表示します。このファイルが無い場合は未配信扱いです。
- 予想器は全成績・競馬場成績・距離成績・騎手成績を使った**未学習の簡易統計モデル**です。確率は校正されておらず的中・利益保証はありません。オッズは現在の自動予想には含めていません。
- 的中率の母数は発走前に予想した後、確定1〜3着を取得できたレースです。未確定・欠損・同着等は含めません。的中率は単勝1点、馬連1点、馬単1点、三連複本線1点、三連複候補最大8点、三連単候補12点の各方式を区別して集計します。三連複の馬番は昇順表示し、着順を問わず照合します。
- 公式ZIPは内部分析に用い、**元データのCSV/ZIPを公開リポジトリへ複製・転載しません**。公開されるのは少数の予想印・馬番・予想結果・集計のみです。出典は[地方競馬情報サイト](https://www.keiba.go.jp/)です。
- 出典データの利用規約、提供ファイル仕様、GitHub側の実行制限により取得・表示に問題が出る可能性があります。
- GitHubで Actions が無効なら `Settings > Actions > General` で有効化する必要があります。定期実行ワークフローが無効化された場合は再度有効にしてください。
- 初回手動テストはリポジトリの `Actions > NAR every-race forecast and verification > Run workflow` から実施できます。アクションが成功すると対象レースの予想・結果が表示されます。
- 仕様や利用条件の更新、公式配布先へのアクセス制限がある場合は自動収集を停止し、許諾されたデータ提供元へ切り替えてください。

# KEIBA LAB v3.2 — iPhone継続利用・公開用パッケージ

このファイル群を **同じフォルダ構造のまま** GitHub Pages等のHTTPSサイトへ配置すると、iPhoneホーム画面から起動できます。`index.html`単体は通常のアプリとして動きますが、オフライン起動等には `sw.js`, `manifest.webmanifest`, `icons/` を含むHTTPS公開が必要です。

## GitHub Pagesで無料公開（GitHub Freeは公開リポジトリが必要）
1. GitHubにサインインし、New repositoryを押す。リポジトリ名を例 `keiba-lab` とし **Public** で作成する。
2. リポジトリの `Add file` → `Upload files` からZIPを解凍した中身の `index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `icons/` などをアップロードする。ZIP自体だけをアップロードしても動きません。
3. `Commit changes` を押す。
4. `Settings` → `Pages` → `Build and deployment` の `Source`: **Deploy from a branch** → `main` → `/(root)` → `Save` を押す。
5. Pagesに表示された公開URLをSafariで開く。例: `https://GitHubユーザー名.github.io/keiba-lab/`（実際のURLはGitHubで確認）。
6. Safari共有メニュー → `ホーム画面に追加` → `Webアプリとして開く` → `追加`。

## 継続利用上の重要事項
- 予想・的中率・モデル・最近取り込んだレース一覧は**その端末のWebアプリ内**で保存。クラウド自動同期や24時間バックグラウンド実行は実装されていません。
- iPhone Safariとホーム画面のWebアプリはデータ領域が異なることがあります。**追加前に「全データをバックアップ」、追加後に「全データを復元」**してください。
- ホーム画面から起動した状態で、定期的に「全データをバックアップ」を押し、JSONをiCloud Drive等へ保管してください。
- 前回取り込んだレース一覧は保持しますが**最新の出馬表ではありません**。利用前に公式情報で更新してください。
- 初期状態は**デモ用の架空馬**を使います。現実の予想精度・利益を示すものではありません。
- 許諾された外部JSONフィードを設定しない限り、JRA/地方競馬から自動取得しません。データフィードは利用者が用意する必要があります。
- 的中率は確定結果を入力してから表示されます。確定結果のない予想は集計対象外です。
- 公開サイトの`index.html`等は誰でも読める可能性があります。**個人情報・APIキー・契約データをGitHubにアップロードしない**でください。ローカルのJSONバックアップも公開しないでください。
- GitHub Pagesを公開していても、利用者の端末ストレージが消去されると履歴が失われます。予想履歴はGitHub上には保存されません。

## 動作・テスト
起動は`index.html`。ホーム画面への追加とオフライン起動はHTTPS公開時にのみ有効。端末内のstorage削除や別originでの公開はデータ引継ぎになりません。

開発・分析用ツールであり、馬券の購入機能はありません。未学習状態のモデル予想に的中保証はありません。
